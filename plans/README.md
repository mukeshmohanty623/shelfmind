# Plans

This folder holds feature plans for this repo, so they travel with the code
(clone the repo on any machine and the plans come with it).

## Convention

- One file per feature/initiative: `NNN-short-title.md`, zero-padded, incrementing
  (e.g. `001-pdf-upload-indexing-pipeline.md`, `002-chat-over-resources.md`).
- Each plan has:
  - **Status** — `draft` / `in progress` / `done` / `superseded`
  - **Context** — why this is being built
  - **Architecture / Flow** — the approach
  - **Task checklist** — mirrors the todo list used while implementing, kept up to date
    so anyone (including a future session on a different machine) can see what's left.
- Edit these files directly as the plan evolves — they're meant to be a living
  reference, not a one-time snapshot.
